GUIDE

사용 방법

  1. API 키 설정.env 파일에 GEMINI_API_KEY를 입력합니다.
  2. 이미지 업로드PNG/JPG/WEBP 이미지를 올립니다.
  3. 영역 선택필요하면 원본의 원하는 부분만 선택해 변환 대상으로 지정합니다.
  4. 옵션 조절선 굵기, 디테일, 스타일을 선택합니다.
  5. 변환 및 저장완성된 결과를 확인한 뒤 PNG로 저장합니다.

공개 배포 시 API 키는 HTML/JS에 넣지 말고 서버 환경변수로 관리하세요.
